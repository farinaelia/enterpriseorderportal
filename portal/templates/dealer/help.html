{{ icon('help-circle', 15) }} Why can’t I edit my order? {{ icon('chevron-down', 14) }}

Orders are locked while they are Submitted, Under Review, Approved or Completed, so the Processor always reviews exactly what you sent. You can edit a Draft at any time, and an order returned for amendment is unlocked for the sections the Processor asked you to correct.

{{ icon('help-circle', 15) }} What happens when an order is returned? {{ icon('chevron-down', 14) }}

The status changes to Amendment Required. You will see the Processor’s reason and which sections need correction. Fix those sections and resubmit. The order keeps the same order number and goes back into the queue.

{{ icon('help-circle', 15) }} Where do I find the reference ID? {{ icon('chevron-down', 14) }}

The reference ID is issued by the Processor when the order is approved. It then appears in the order header and in the Reference ID column of My Orders.

{{ icon('help-circle', 15) }} Which file types can I upload? {{ icon('chevron-down', 14) }}

PDF, JPG, PNG and XLSX files, up to 10 MB per file.
