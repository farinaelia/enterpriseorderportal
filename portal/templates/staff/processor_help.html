Help

How reviewing works in this portal.

  1. Start review. Open a Submitted order and press Start review. It becomes Under Review.
  2. Check. Read each tab. Documents can be previewed when a real file was uploaded.
  3. Approve. Needs every required document. A reference ID such as REF-MVP-78422 is created automatically.
  4. Or request an amendment. Choose a category, the sections to fix and a clear reason. The dealer can then edit and resubmit the same order.
  5. Complete. After an approved order is activated, mark it completed.

Every action is written to the order's activity history with your name and the time.
